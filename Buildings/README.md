# Buildings

This folder contains the active building-data mapping workflow for the City Digital Twin.

## Current workflow

The current implementation maps Overture Maps building data into the City Digital Twin RDF model.

- **Mappings/** - human-readable Overture building mapping specification.
- **Scripts/** - Overture-to-RDF/Turtle transformation code.
- **Diagrams/** - building-domain diagrams when available.

Large Overture source files and generated production RDF files are kept outside GitHub.
