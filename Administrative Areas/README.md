# Administrative Areas

This folder contains the active Toronto administrative-area mapping workflow.

## Contents

- **Scripts/** - transformation scripts used to generate RDF/Turtle.
- **Diagrams/** - diagrams supporting the administrative-area model.
- **Validation/** - validation reports and checks for generated administrative-area data.
- **Mappings/** - human-readable mapping specifications when available.

The current Toronto workflow covers wards, neighbourhoods, census tracts, and their relationship to the City of Toronto.
