# Services and Amenities

This folder contains mappings, scripts, and diagrams for city services and amenities.

OpenStreetMap is treated as a data source within this domain rather than as a top-level repository category.

- **Mappings/** - human-readable service and amenity mappings.
- **Scripts/OpenStreetMap/** - OpenStreetMap and Overpass-based transformation scripts.
- **Diagrams/** - service and amenity ontology diagrams.
